REIGN IN WEALTH RETREATS - FAVICON + GALLERY PATCH
=================================================
This patch is for the Node 22 / cPanel project currently at
/workspaces/Reign_in_Wealth_Retreats (Git repository root).

WHAT CHANGED
- Green-and-gold RW favicon extracted from the supplied logo
- New /gallery page with filters, photos, and accessible fullscreen viewer
- Gallery links in header, footer, travel journal, and sitemap
- Public gallery importer: npm run gallery:import
- Documentation: reign-in-wealth-retreats/docs/GALLERY.md
- No photos from the external Google Drive folder are bundled: its contents
  could not be read through the connected Google Drive mount. The page uses
  explicitly labelled destination imagery until approved photos are imported.

APPLY IN CODESPACES (do NOT unzip directly on the live cPanel server)
  cd /workspaces/Reign_in_Wealth_Retreats
  unzip -o Reign-Retreats-Gallery-Favicon-Patch.zip
  rm -f reign-in-wealth-retreats/src/app/icon.svg
  cd reign-in-wealth-retreats
  npm ci
  npm run typecheck
  npm run build
  cd ..
  git status
  git add -A
  git commit -m "Add branded favicon and photo gallery"
  git push origin main

DEPLOY ON CPANEL
  - Open cPanel > Git Version Control > Manage > Update from Remote
  - Then use Deploy HEAD Commit. The existing deployment script copies src,
    public, scripts, etc. to /home/reigninw/reign-wealth-retreats-app, runs
    npm ci/build, and restarts Passenger.
  - The updated deploy script removes the old icon.svg in the production app.
  - If deploying manually, also delete the old app src/app/icon.svg before building.
  - Do not overwrite the production .env, data/, media,
    backups, or app configuration. Update source/build files only.
  - Visit https://reigninwealthretreats.com/gallery and
    https://reigninwealthretreats.com/icon.png after deployment.
  - If the old favicon appears, hard refresh or use a private browser window.

ADDING ORIGINAL PHOTOS
  - Download the shared Drive folder into Codespaces, review images and consent.
  - Run npm run gallery:import -- /path/to/photos --album "Ghana 2026" --location "Ghana"
  - Review src/data/gallery-photos.json, generated public/gallery/*.webp,
    then commit/push/deploy those files as above.

NOTE
  - The Node.js version requirements and cPanel scripts from the previous
    Node 22 package are retained.
